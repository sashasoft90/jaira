- To choose the model each spawned tab starts on, map tiers to models in `"models"` in `~/.jaira/settings.json` (e.g. `{"cheap": "sonnet", "strong": "opus", "mini": "haiku"}`) or per board in `.jaira/models` (`cheap = sonnet`, one line per tier; it wins over the machine's); spawn.sh then starts each lane on its tier's model, and with neither set every tab starts plain `claude` as before.
- To choose the model of a worker or dispatcher tab, set the `"worker"` entry in the same map; without it they start on the model of `strong`.
- Read `lane_models` and `worker_model` in `jaira roles list --json`, and the `worker model:` line in `jaira roles list`, to see which model each tab will start on.
- Install the new jaira binary before `jaira roles install`: the new spawn.sh reads the models from `jaira roles list`, and with an older jaira on PATH every tab keeps the account's default model.
